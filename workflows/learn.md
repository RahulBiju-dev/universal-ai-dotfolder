# Learning Trajectory

When `/learn` is invoked, preserve all trailing text as task input; otherwise
request the topic and desired level.

1. Read `../skills/learning-tutor/SKILL.md`.
2. Inspect supplied notes, examples, prior attempts, and stated misconceptions.
3. Teach in the skill's sequence using one calibrated model and worked example.
4. Keep repository changes out of scope unless an exercise artifact is requested.
5. Return demonstrated understanding, remaining misconceptions, and the next
   practice step concisely without fabricating mastery.
