# Visual Systems

## Establish a Thesis

- Describe the interface's visual idea in one sentence before implementation.
- Tie the idea to the product, audience, content, and primary action.
- Select one signature motif such as editorial rhythm, technical precision, tactile depth, or expressive typography.
- Keep the motif recognizable without applying it to every component.
- Preserve an established brand system unless the task explicitly authorizes a redesign.

## Define Bounded Tokens

- Use one body family and at most one intentional display family.
- Reuse local or existing fonts; avoid adding a font network dependency without authority.
- Define a compact type scale with clear heading, body, label, metadata, and numeric roles.
- Define spacing from a small consistent scale rather than arbitrary per-component values.
- Limit radii and elevations to a few semantic levels.
- Use a restrained neutral foundation and deliberate accent roles.
- Assign colors by purpose such as surface, text, border, action, success, warning, and danger.
- Verify contrast before treating a color as available.
- Avoid turning dark themes into automatic neon palettes or light themes into empty white canvases.

## Compose with Hierarchy

- Make the primary task and reading order evident without explanatory decoration.
- Vary scale, density, alignment, and whitespace to establish rhythm.
- Use asymmetry only when it preserves scanning order and responsive stability.
- Group related controls through proximity before adding containers.
- Reserve borders, fills, and elevation for meaningful separation or interaction.
- Let dense tools remain dense when efficiency matters; do not force landing-page spaciousness onto them.
- Let marketing surfaces breathe without sacrificing concrete content or reachable actions.
- Stress layouts with long names, localization, large numbers, missing media, and narrow widths.

## Reject Generic Defaults

- Reject an unmotivated purple-to-blue gradient as the default identity.
- Reject gratuitous glass panels, glowing blobs, noise overlays, and blurred backgrounds.
- Reject wrapping every section, metric, or sentence in an identical rounded card.
- Reject using pills for ordinary buttons, navigation, filters, and labels simultaneously.
- Reject oversized heroes that consume the viewport without useful content or action.
- Reject repetitive centered headings followed by interchangeable three-column feature grids.
- Reject generic dashboard tiles when hierarchy, comparison, or workflow demands another structure.
- Reject emoji as interface iconography when an existing icon system or clear text label is available.
- Reject stock filler copy, anonymous avatars, decorative charts, and invented product claims.
- Reject arbitrary shadows, gradients, radii, and accent colors that lack token roles.
- Reject decorative scroll reveal and staggered entrance motion as default behavior.
- Override these rejections only when the established product language or explicit brief requires the pattern.

## Use Motion and Media Deliberately

- Use motion to explain causality, continuity, hierarchy, or status.
- Keep durations short, easing consistent, and interaction feedback immediate.
- Provide a reduced-motion path that removes nonessential movement without hiding information.
- Prevent animation from delaying input, focus, reading, or task completion.
- Use meaningful product imagery, diagrams, or generated assets only when they improve comprehension or identity.
- Preserve aspect ratios, reserve media dimensions, provide alternatives, and avoid cumulative layout shift.
- Prefer one strong visual asset over a collection of unrelated decorative images.

## Maintain Distinctiveness Responsibly

- Create distinction through content-specific composition rather than novelty alone.
- Keep controls familiar even when the surrounding visual language is expressive.
- Preserve readability, discoverability, and task speed over decorative ambition.
- Remove any effect that weakens contrast, obscures state, or competes with the primary action.
