# Universal AI Dotfolder
A centralized boilerplate repository designed to unify AI agent workflows, executable skills, and project context across multiple autonomous development environments.

Instead of rewriting agent rules and tool schemas for every new assignment, this repository provides a single, portable directory structure. By cloning this toolkit and renaming it to your target platform's expected configuration folder (e.g., `.agents`, `.cursor`, or `.claude`), you instantly deploy a standardized suite of development tools.

**Key Features:**

* **Write Once, Run Anywhere:** A unified architecture that intelligently overlaps the routing rules of Google Antigravity, Claude Code, and Cursor. Tools consume what they recognize and safely ignore the rest.
* **Portable Execution:** Carry your custom Python integration testing pipelines, Bash compilation scripts, and MCP servers into any new workspace or virtual machine.
* **Standardized Context:** Enforce global behaviors, C programming standards, and specific system architectural rules across all AI interactions.
* **Unified Slash Commands:** Instantly provision commands like `/run-pipeline` or `/debug-mem-leak` natively in your chat or terminal interfaces.
