# Audit Accessibility

Preserve all text following `/a11y` as task input. When empty, use the active
interface and identify the user journey under review.

Resolve the configuration root as the parent of this command file's directory.

1. Read its `skills/accessibility-auditor/SKILL.md`.
2. Inspect semantics, keyboard and focus behavior, visual presentation, forms,
   media, dynamic states, errors, and available automated evidence.
3. Follow the skill's manual and automated workflow, decision boundaries,
   quality gates, and output contract.
4. Keep auditing read-only unless remediation is explicitly requested; ask
   before launching external tools.

Report severity, reproduction, user impact, criterion, remediation, and tested
states concisely. Never claim conformance or a fixed barrier without relevant
manual and executed evidence.
