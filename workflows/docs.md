# Documentation Trajectory

When `/docs` is invoked, preserve all trailing text as task input; otherwise
request audience, behavior, format, and destination.

1. Read `../skills/documentation-writer/SKILL.md`.
2. Inspect authoritative code, interfaces, commands, configuration, versions,
   tests, and existing documentation.
3. Structure the smallest complete task-oriented document.
4. Write only when a destination or documentation change is requested.
5. Return changed paths and verified commands, examples, links, and limitations
   concisely without inventing support or outputs.
