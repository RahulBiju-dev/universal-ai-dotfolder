# Accessibility Trajectory

When `/a11y` is invoked, preserve all trailing text as task input; otherwise
identify the active user journey.

1. Read `../skills/accessibility-auditor/SKILL.md`.
2. Inspect semantics, keyboard and focus behavior, presentation, forms, media,
   dynamic states, errors, and available automated evidence.
3. Verify material barriers manually where the environment permits.
4. Keep auditing read-only unless remediation is requested; ask before external
   tools.
5. Return severity, reproduction, impact, criterion, remediation, and tested
   states concisely without claiming conformance.
