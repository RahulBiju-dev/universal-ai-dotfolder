# Rubber-Duck Trajectory

When `/rubber-duck` is invoked, preserve all trailing text as task input;
otherwise ask the user to state the problem and current mental model.

1. Read `../skills/rubber-duck/SKILL.md`.
2. Inspect only artifacts needed to resolve a concrete contradiction.
3. Ask one high-information Socratic question and incorporate each answer.
4. Keep the trajectory read-only and stop before unsolicited implementation.
5. Return discovered evidence, contradictions, and the next experiment
   concisely without treating an untested hypothesis as resolved.
