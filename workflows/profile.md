# Profiling Trajectory

When `/profile` is invoked, preserve all trailing text as task input; otherwise
request the workload and user-visible metric.

1. Read `../skills/performance-profiler/SKILL.md`.
2. Inspect correctness checks, build mode, workload, environment, complexity,
   prior data, and available profilers.
3. Capture comparable bounded samples and attribute dominant cost.
4. Keep source unchanged unless optimization is requested; ask before
   privileged, installed, or costly profiling.
5. Return baseline, method, variance, hotspots, and uncertainty concisely
   without fabricating measurements.
