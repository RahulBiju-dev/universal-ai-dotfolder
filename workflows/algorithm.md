# Algorithm Trajectory

When `/algorithm` is invoked, preserve all trailing text as task input;
otherwise request the formal problem and input constraints.

1. Read `../skills/algorithm-designer/SKILL.md`.
2. Formalize inputs, outputs, invalid states, scale, and performance targets.
3. Compare candidate methods and select structures from explicit invariants.
4. Keep design read-only unless implementation is explicitly requested.
5. Return the method, proof sketch, time-space bounds, tradeoffs, and tests
   concisely without treating examples as proof.
