# Frontend Trajectory

When `/frontend` is invoked, preserve all trailing text as task input; otherwise
use the active UI request and available design context.

1. Read `../skills/frontend-design/SKILL.md`.
2. Inspect routes, components, tokens, assets, content, states, responsive
   behavior, and accessibility conventions.
3. Design the complete hierarchy and interactions before implementing requested
   changes.
4. Mutate files only when implementation is explicit and stay within the target
   surface.
5. Return changed surfaces, state coverage, responsive and accessibility
   evidence, and unrun checks concisely.
