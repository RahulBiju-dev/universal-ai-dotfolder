# Bootstrap Trajectory

When `/bootstrap` is invoked, preserve all trailing text as task input;
otherwise require an explicit target and objective.

1. Read `../skills/project-bootstrapper/SKILL.md`.
2. Inspect target emptiness, parent conventions, available tooling, supported
   environments, build, tests, configuration, and documentation needs.
3. Select the smallest coherent scaffold and verify every destination collision.
4. Create files only for an explicit approved target; never overwrite, install,
   initialize remotes, or publish silently.
5. Return created paths, conventions, validation, and next commands concisely
   without claiming unrun setup.
