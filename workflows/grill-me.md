# Requirement Grill Trajectory

When `/grill-me` is invoked, preserve all trailing text as task input; otherwise
use the active proposal or request the missing source request.

1. Read `../skills/requirement-griller/SKILL.md`.
2. Inspect only evidence needed to expose scope, behavior, safety,
   compatibility, cost, and acceptance decisions.
3. Ask the highest-impact unresolved questions in the skill's prescribed order.
4. Stop at the skill's sufficiency boundary without designing or editing.
5. Return the resolved execution contract, open decisions, and evidence
   concisely without fabricating agreement.
