# API Trajectory

When `/api` is invoked, preserve all trailing text as task input; otherwise use
the active interface proposal.

1. Read `../skills/api-designer/SKILL.md`.
2. Inspect consumers, current contracts, implementations, schemas, errors,
   authorization, versioning, operations, and tests.
3. Define operations and compatibility behavior using the skill's quality gates.
4. Keep design read-only unless implementation or specification edits are
   explicitly requested.
5. Return the contract, decisions, assumptions, and verification needs
   concisely without claiming unsupported consumers.
